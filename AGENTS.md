# AGENTS.md — sing-and-guess

iOS Swift 项目。XcodeGen 管理项目配置。

## 命令
```bash
make generate     # xcodegen generate
make open         # open *.xcodeproj
make build        # xcodebuild (simulator)
make test         # xcodebuild test
make clean        # 清理
```

## 技术栈
Swift / SwiftUI / XcodeGen / iOS

## 约定
- MVVM 架构
- CI: macos-latest runner
