# Changelog

## [1.0.0] - 2026-06-08
### Added
- Initial release
- Song library with 50+ songs across 6 genres (Chinese, English, Cantonese, etc.)
- MVVM architecture with GameViewModel orchestrator
- Game phases: Setup → SongReveal → Singing → Guessing → Scoring → Results
- Progressive hint system
- Scoring with time bonus
- Player management with emoji avatars
- Custom FlowLayout for genre tags
- XcodeGen project configuration
- SwiftLint pre-build script
